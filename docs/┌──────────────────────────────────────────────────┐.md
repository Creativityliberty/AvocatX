EXTERNES / UTILS  
──────────────────────────────────────────────  
  stt.py              → OpenAI /v1/audio/transcriptions  •  Gemini Live Streaming  
  legifrance.py       → OAuth2 token \+ /search (sandbox-api.piste.gouv.fr)  
  ocr.py              → Tesseract (Docker)  /  pdf-parse  
  anonymise.py        → regex \+ chat GPT  
  embedding.py        → sentence-transformers (all-MiniLM) \+ faiss-cpu  
  export.py           → WeasyPrint CLI  ⇒  dossier.pdf / dossier.zip

RUN LOCALLY  
───────────  
\`\`\`bash  
\# 1\. Install  
poetry install  
\# 2\. Transcrire \+ flow complet sur fichier  
poetry run defenseur-ia demo.mp3            \# via cli.py  
\# 3\. Serveur  
poetry run uvicorn defenseur\_ia.server.main:app \--reload \--port 8000
